# Todo App 🧾

This is a todo app made with ReactJS, NodeJS + Express, and MongoDB <br />
Demo: **https://todo-app-p.netlify.app/**
<br />
<br />

## Core Features ⭐
- Add, update, and delete todos
- Filter completed todos
<br />
<br />

## Tech Stack 🚀
- **Frontend**: ReactJS, CSS
- **Backend**: NodeJS + Express
- **Database**: MongoDB (url in .env not in git)
- **Hosting**: Netlify(Frontend), Render(Backend)
<br />
<br />

## Setup & Installation ⚙️

### 1. Clone the repository
```bash
git clone https://github.com/celinastha/todo_app
cd todo_app
```

### 2. Create .env in backend/
in backend/.env <br />
MONGODB_URL = your-mondodb-url <br />
PORT=4000 # backend server port

### 3. Install dependencies
Frontend: cd frontend && npm install <br />
Backend: cd ../backend && npm install

### 4. Run development servers
In terminal 1 (backend): cd backend && node server.js <br />
In terminal 2 (frontend): cd frontend && npm start
